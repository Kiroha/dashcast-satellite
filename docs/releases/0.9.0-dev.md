# DashSat 0.9.0-dev — Roundabouts without a guessed exit

Application versionName: **0.9.0-dev**. Version code: **10**.
Recognized clockwise and counterclockwise roundabouts can now remain active when Google Maps
provides no exit number. Previously such a source snapshot stopped guidance even when its
direction and distance were known. The sender negotiates this optional capability from the
authenticated receiver and omits the exit field rather than inventing an ordinal.

**Install DashCast 1.9.21-beta on the vehicle and this DashSat update on the Carlinkit/Tbox**
to use generic roundabouts. Both applications must be updated. An older receiver continues
to receive a fresh ordered stop for an unsupported generic roundabout; it is never sent
an invented exit or a maneuver that it did not negotiate.

Install manually or through **Updates** over the existing 0.8.0-dev application without
uninstalling. The published development channel keeps the existing `.debug` package and
independent Android signing identity, so pairing and settings are preserved. No new pairing
is required. This APK remains a development build and is not the separate production package.

## Guidance behavior

- Extract French numeric and spelled exit ordinals beside `sortie`, while retaining the
  existing multilingual parsing and captured Maps image corpus.
- Preserve genuinely absent exits only with recognized roundabout circulation and a valid
  maneuver distance. Malformed, contradictory and out-of-range exit evidence stays unsupported.
- Accept generic-roundabout support only from a strict authenticated welcome capability;
  reset it whenever the connection changes. Source age, stops, replay protection, pinned WSS
  and the selected navigation source keep their existing behavior.
- Keep the 0.8.0-dev sharing flow: video can start before the DashCast viewer opens and waits
  for that viewer within the same authorized foreground capture session. Guidance and video
  remain separate states; this release changes no capture or listener lifecycle.

DashSat contains no OEM vehicle outputs or platform keys. DashCast decides the native display
mapping and the traffic-side override. Protocol v1 and its fixtures remain pinned to the
reviewed receiver commit `784ad22e2ffd40d354b16d0f195cd10794b47454`.

## Validation and limits

Checks passed: **189 JVM tests across 30 suites**, debug and release lint with **zero issues**,
debug APK assembly, the reviewed native WebRTC archive, guidance/pairing protocol hashes and
exact receiver fixture parity. The APK's new version and code, development package and unchanged
signing certificate are verified against 0.8.0-dev.

Actual Carlinkit source extraction and generic roundabout rendering still need vehicle tests.
No on-car generic-roundabout result, hardware decoder use, video latency or resource savings
is claimed from these local checks. The receiver's experimental parked music STOP probe is
separate from this application and does not change Satellite guidance.
