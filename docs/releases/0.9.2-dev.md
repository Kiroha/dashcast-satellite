# DashSat 0.9.2-dev

- Add **Send diagnostics to DashCast** to the video page. Send a small manual video-history snapshot over the existing local connection, then return to DashCast and send a normal bug report. Telegram or WhatsApp is not needed on the box.
- Show received only after DashCast acknowledges its RAM-cache commit. Disconnected/unsupported states, a five-second confirmation timeout and retained last-transfer results remain explicit. **Copy video diagnostics** is still available.
- Keep exports strictly typed and bounded: fixed stages/states/causes, counters, local attempt ordinals and elapsed ages only. No SDP, credentials, addresses, route text or raw notification content.

Requires DashCast 1.9.25-beta or another receiver advertising video diagnostics schema 1. This release improves diagnostic transfer; it does not establish a fix for the remaining vehicle video issue. Real Tbox video/performance acceptance is still pending.
