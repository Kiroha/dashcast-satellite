# DashSat 0.9.3-dev

Covering the shared app while returning to DashSat no longer stops its authorized capture session after five seconds. Android content hiding and VirtualDisplay pause now suspend video, release the current sender peer/encoder and keep the same user-authorized projection/display available. Open the app Android is actually sharing and return to DashCast to resume with a fresh video negotiation. No new consent is needed while that same session remains valid.

The paused state keeps **Stop video sharing**, **Open selected app** and the foreground notification available. Encoding, static-frame repeats, native statistics and the encoder watchdog stay inactive while the source or viewer is unavailable. Both Android source visibility and display resume must restore, followed by a new platform texture; cached or late frames cannot make an interrupted source fresh. Source epochs also fence the old peer, its watchdog and texture delivery even when visibility restores before the queued pause is processed.

Stop, Android revocation, display stop, lock/screen-off, control loss and fatal errors still end sharing and require new Android consent. No capture token reuse, second VirtualDisplay, hidden independent app display, remote input, codec fallback or receiver change is introduced. Guidance remains independent. Diagnostics retain the existing protocol schema and fixed states.

Compatible with the existing DashCast receiver; no new pairing or receiver update is required. Actual resumed video and lower vehicle CPU/GPU use remain to be validated on the Tbox and vehicle. This corrects capture-session continuity; it does not establish a fix for the separate first-frame H264 decode observation.

Validation: **229 unit tests across 35 suites** passed with no failures, errors or skips. Debug assembly, lint (zero issues), the pinned WebRTC archive check and protocol/fixture hash checks passed. State-machine and service checks cover source hiding/display pause, fresh-texture gates, ordered resumes, no idle stats polling, active Stop controls and terminal failure cleanup. VersionCode **13**, development package/signing identity unchanged.
