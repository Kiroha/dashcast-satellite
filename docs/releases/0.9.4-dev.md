# DashSat 0.9.4-dev

Adds bounded first-frame diagnostics for investigations where DashCast receives video packets but
has not decoded an image. Manual diagnostic transfer now includes the latest original sender sample
from up to four attempts, with nullable encoded/keyframe counts and RTCP feedback. Closed attempts
remain available after switching between CarPlay and DashCast.

The optional details extension is negotiated per authenticated connection. Older receivers continue
to receive the legacy snapshot and acknowledgement. Capture consent, source visibility, codec
selection, hardware encoding and guidance behavior are unchanged. This release provides evidence;
it does not claim to fix the black image or establish vehicle decoding performance.

Validated with 233 JVM tests, pinned protocol/fixture verification, debug assembly and Android lint
(zero issues). This includes legacy/detail capability combinations over pinned WSS, immutable queued
snapshots, strict nullable counter validation and bounded historical retention. Vehicle first-image
validation remains pending.
