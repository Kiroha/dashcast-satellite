# DashSat 0.9.6-dev

Adds bounded, content-free diagnostics of actual hardware H264 output for the persistent black
first image investigation. The first output and up to three later declared key outputs are
inspected for Annex B SPS/PPS/IDR headers and fixed SPS header bytes. SDK image dimensions are
reported separately from negotiated codec parameters; no full SPS validation is claimed.

Use with DashCast 1.9.41-beta, reproduce sharing, choose **Send diagnostics to DashCast**, wait for its received
confirmation, then create the DashCast bug report. Pairing and navigation remain independent.
Older receivers continue to receive the previous diagnostics format.

This build does not change codec, keyframe recovery, capture consent or receiver decoding, and
cannot yet promise a first decoded image or lower vehicle CPU/GPU use. No raw media bytes, SDP,
route text or codec implementation names are retained in diagnostics.

Validation: 264 unit/protocol/transport tests pass, debug lint reports zero issues and debug
assembly passes. Final release checks are recorded with the frozen artifacts. Real Carlinkit
hardware output and vehicle decoding still require a parked-device test.
